# TaskFlow

A responsive task management application built with JavaScript. TaskFlow helps users organize their work, manage projects, set priorities, and keep track of their tasks in one place.

## Features

- **Task management:** Create, edit, and delete tasks.
- **Project organization:** Create projects and organize tasks within them.
- **Task details:** Add descriptions, due dates, and priority levels.
- **Completion tracking:** Mark tasks as completed or active.
- **Project management:** Select and delete projects, with a protected default project.
- **Data persistence:** Automatically save tasks and projects using browser localStorage.
- **Responsive interface:** Adapted for desktop, tablet, and mobile screens.
- **Form validation:** Validate task and project input.
